# AI Agents Hub

> **Un framework modulaire pour collaborer avec des agents IA et des *skills* réutilisables.**

Ce dépôt permet de structurer, versionner et orchestrer des **agents IA** (LLM comme Mistral, Claude, etc.) et des **skills** (compétences modulaires) pour automatiser des tâches complexes : analyse de code, recherche web, traitement de données, etc.
